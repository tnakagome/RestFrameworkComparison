## About
This repo is based on a Ktor project auto-generated by IntelliJ IDEA. Functions are split into multiple source files from the beginning. This is more typical than the single-source version.

## How to Test the Program
Set up Java SDK (17 or higher) and [IntelliJ IDEA](https://www.jetbrains.com/idea/) as prerequisites. Gradle is optional as it comes with the IDE.

At the time of this writing, the versions used are:
```
IntelliJ IDEA 2026.2.3
Ktor 3.5.2
```

1. Run IntelliJ IDEA and create a new ktor project. In the New Project dialog, set Name to `App` and Group to `KtorSample`, then press the Next button.
2. In the Plugins screen, search and add the "kotlinx.serialization" plugin to the project, then press "Create".
3. Several files will be generated. Open `application.yaml` in the `src/main/resources` section and update the port from `8080` to `18080`.
4. Copy the `Greeting.kt` in this repo into the `src/main/kotlin` directory.
5. Overwrite the `Routing.kt` in the `src/main/kotlin` directory using the one in this repo.
6. Build and run the project in IntelliJ IDEA.
If the server starts successfully, you'll see the following output within the IDE:
```
2026-09-22 19:12:49.621 [main] INFO  Application - Application started in 0.181 seconds.
2026-09-22 19:12:49.688 [main] INFO  Application - Responding at http://0.0.0.0:18080
```
7. Open a terminal and run the `test.sh` in this repo.
```
$ ./test.sh
Hello, Taro
```
To test the GET capability, use telnet:
```
$ telnet localhost 18080
Trying ::1...
Connected to localhost.
Escape character is '^]'.
GET /hi/Taro HTTP/1.0

HTTP/1.0 200 OK
Content-Length: 12
Content-Type: text/plain; charset=UTF-8

Hello, Taro!
```
